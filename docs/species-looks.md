# Почерк видов — что генератор умеет и где это будет (30.10, черновик)

Проблема: вид сейчас — это цвет на случайной форме. Хрусталь, аметист и дымчатый кварц — одна и та же «призма»,
у любой призмы любая раскладка (одиночный, колонна, щётка, веер, пластины, плитки, груда), у любого кристалла
жеода/друза/кристалл с одними весами. Новый вид не ощущается новым.

Правила переделки:
1. **Ничего красивого не теряем.** Каждая возможность генератора (таблица 1) остаётся хотя бы у одного вида
   или в общем слое. Где реальная минералогия против — допускаем игровую условность.
2. **Два слоя.** Видовой (форма, пропорции, раскладки, типы находок, порода, фирменная деталь) и общий — может
   выпасть у любого вида (таблица 2): наросты, грибы, мох, растения, редкие признаки, легендарные эффекты.

## 1. Что генератор умеет → у кого это будет

Сейчас = у кого может выпасть сейчас (пулы рудников 1–3). Будет = предложение. «—» = сейчас нет ни у кого из пулов.

### Формы кристалла (habit, `rock_kit.gd crystal`)
| Форма | Сейчас | Будет |
|---|---|---|
| prism — шестигранник с острием | хрусталь, аметист, дымчатый, берилл, аквамарин, изумруд | хрусталь (длинный), аметист (короткие пирамидки), дымчатый (толстый), берилл/аквамарин/изумруд (тупой торец — новое: без острия) |
| blade — плоское лезвие | селенит, целестин | селенит (длинные), целестин (короче, голубые) |
| scaleno — «собачий зуб» | кальцит | кальцит |
| cube | флюорит, пирит | флюорит, пирит (+ штриховка) |
| octa | куприт | куприт; флюорит изредка (сколотый октаэдр — условность) |
| dodeca | альмандин | альмандин |
| barrel — бочонок | — (рубин, сапфир вне пулов) | рубин, сапфир (будущие россыпи) |
| nugget | золото, медь | золото, медь |
| botryoid — почки | малахит, хризоколла, опал | малахит, хризоколла, опал; азурит — «солнца» (radial), не почки |

### Раскладки (form, `specimen_builder.gd`)
| Раскладка | Сейчас | Будет |
|---|---|---|
| single — один кристалл | все призмы/лезвия/кубы | хрусталь, дымчатый, аквамарин, изумруд, кальцит, флюорит |
| columnar — колонна сросшихся | призмы | дымчатый, аквамарин, берилл |
| cluster — щётка | все | хрусталь, аметист, кальцит, флюорит, пирит, целестин |
| slabs — пачка пластин | призмы, лезвия | селенит, целестин |
| radial — веер / «солнце» | призмы (редко), друзы | азурит («солнце»), селенит изредка |
| rosette — роза | лезвия | селенит («роза пустыни») |
| floater — висящий без породы | признак floater у вытянутых | общий слой (признак), чаще у хрусталя |
| hopper — ступенчатые кубы | некубическое cube (галит — вне пулов) | **сирота в пулах**: флюорит изредка (условность) или будущий висмут/галит |
| pile — груда | многие | альмандин (россыпь вросших), куприт |
| hexplates — шестигранные плитки | barrel, prism редко | **сирота в пулах**: рубин/сапфир (будущие); пока — аквамарин изредка |
| geode | любой кристалл (kind geode 1.4) | аметист (главное), целестин, хрусталь изредка |
| vein — жила в кварце | золото, медь | золото, медь |

### Тип находки (kind, `stones.gd`)
crystal / druse / geode с одними весами у всех → у каждого вида свои веса (аметист: жеода/друза, альмандин:
кристалл, селенит: кристалл/пластины, хрусталь: кристалл/друза).

### Блеск (lustre)
| Блеск | Сейчас | Будет |
|---|---|---|
| glass | 80% стеклянных | основной |
| dark — непрозрачный с масляным переливом | 20% любых стеклянных | дымчатый (разновидность «морион»), 5% у остальных как редкий признак «гематитовая корка» |
| metal | пирит, самородки | без изменений |

### Порода-хозяин (rock)
basalt, slate, ironstone, limestone, quartzite — сейчас случайно у всех → предпочтение по виду (аметист — базальт,
кальцит — известняк, пирит — сланец, золото — кварцит, альмандин — сланец), с долей случайной (условность).
Новая порода не обязательна; слюдистый сланец для граната — хорошо бы позже.

## 2. Общий слой — может выпасть у любого вида (не трогаем)
- **Наросты** (accents): fibre puffs, golden strands, lichen, needles, crystal crust, hematite dust, fern fronds,
  tiny flowers, dark inclusions, colour clouds (только в прозрачном стекле).
- **Грибы** (`SpecFungi`, свой поток, ~14%), **мох/кораллы** (признаки).
- **Редкие признаки**: rainbow film, aurora, gas bubbles, druzy coat, twin, phantom, rutilated, sceptre, floater,
  zoned, silver rim, etched, gold flecks, anomalous.
  Исключение: часть признаков станет фирменной деталью вида (всегда), а у остальных — по-прежнему редкой:
  `zoned` — всегда у флюорита и аметиста; `phantom` — чаще у хрусталя; `sceptre` — чаще у аметиста.
- **Легендарные эффекты** — по телу камня (стекло/металл/ископаемое), как сейчас.
- **Крошащаяся порода, размер, место для мха** — как сейчас.

## 4. Сироты и вне пулов
- Раскладки **hopper** и **hexplates** в текущих пулах никому не нужны → оставляем их флюориту/аквамарину изредка
  (условность), пока не придут свои виды (висмут/галит, рубин/сапфир).
- Виды вне пулов (код остаётся): рубин, сапфир, алмаз, галит, сильвин, ангидрит, пироп, хризолит, жемчуг,
  цветок в кварце, фульгурит → будущие рудники (`docs/collection.md`).

## 5. Как делать
1. `SP[вид].look` в данных: форма, пропорции, раскладки с весами, типы находок, блеск, порода с весами, фирменная деталь.
2. `SpecGenome.of` и `Stones.roll` читают профиль, без профиля — как сейчас (ничего не ломается).
3. Новое по деталям: тупой торец призмы, зоны у аметиста/флюорита постоянно, тёмность стекла (дымчатый), штриховка
   пирита, дендриты меди.
4. Витрина «по 3 образца каждого вида» на рудник — проверка, что вид узнаётся.

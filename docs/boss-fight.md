# Бой с боссом: логика

Согласовано с владельцем 25.10.2026. Внешний вид боссов прорабатывается отдельно (`docs/boss-art.md`);
здесь — только правила боя. Общий план прогресса — `docs/progression-redesign.md`, эпик E в `docs/backlog.md`.

## 1. Суть

Босс стоит на последней глубине рудника (у Old Adit — 350 м). Бой — уровень из **трёх полей подряд**, как
многоэтапные уровни Royal Match: разбил треть здоровья босса — поле уезжает вверх, снизу въезжает новое.
Каждое поле — одна фаза босса. Поля босса сделаны руками (не генератор), одни и те же для каждой попытки.

## 2. Урон

- Бьют **жёлтые кристаллы**: каждый разбитый жёлтый камень — урон боссу.
- Жёлтый камень **с рудой** (золотые жилы) бьёт втрое сильнее — признак руды здесь работает как уязвимое место.
- Спецфишка, сработавшая на поле, — небольшой урон сверх разбитых ею камней.
- Остальные цвета урона не дают: они нужны, чтобы собирать ряды и спецфишки.
- Числа — крупные, как на макете (здоровье 420): жёлтый 10, жёлтый с золотом 30, спецфишка 20.
  Подгоняются автоигроком.

Руду в бою **не добывают** (у глубины босса нет жилы): в шапке вместо плашек руды — полоска здоровья
с рисками на 2/3 и 1/3.

## 3. Три поля = три фазы

| Поле | Здоровье | Что делает босс |
|---|---|---|
| 1 | 420 → 280 | одно-два простых действия, раз в 3 хода |
| 2 | 280 → 140 | добавляется новое действие |
| 3 | 140 → 0 | действует раз в 2 хода, самое сильное действие |

- Смена поля: последний удар по фазе → короткая реплика босса → поле уезжает вверх, новое въезжает снизу.
  Лишний урон сверх порога фазы не переносится (каждое поле — свой кусок здоровья).
- Форма и препятствия каждого поля — свои (рисуются руками в данных босса).

## 4. Действия босса

- Босс действует **раз в N ходов** игрока; что он сделает, видно **заранее**.
- Все действия собраны из препятствий, которые игрок встречал на глубинах этого рудника («экзамен рудника»).
  Для Old Adit:

| Действие | Что делает | Как ответить |
|---|---|---|
| Кольца | крепи на 4–6 камней | разбить крепи или обойти |
| Обвал | песок/гранит на отмеченные клетки | увести камни из-под отметки |
| Клад | +здоровье за каждый жёлтый камень с рудой на поле | успеть разбить золото |
| Ядовитое дыхание (поле 3) | 3–4 клетки газа | гасить газ, пока не расползся |

## 5. Окно реплик и индикация ударов

Облачко рядом с боссом — одно на всё общение (макет 25.10):
- **реплики**: на старте, при смене поля, на большое комбо, когда теряет фазу, при победе/поражении;
- **намерение**: значок действия + отсчёт ходов («2»), в последний ход перед действием — подсвеченные клетки,
  куда он ударит. Реплика и намерение могут идти вместе: текст сверху, значок с отсчётом снизу.
- Связь с полем — через анимацию: босс бьёт по рамке → камни/крепи падают на отмеченные клетки.

## 6. Ходы, поражение, награда

- Ходы: **число пока не решено** — подбирается автоигроком под цель «живой игрок выигрывает с 2–3 попыток».
  Вариант для начала: общий счётчик на весь бой, при смене поля +5 ходов.
- Поражение (кончились ходы): попытка заново с первого поля; каждый проигрыш снимает боссу 5% здоровья
  на следующую попытку (мягкое поражение).
- Победа: 9 жеод, выбрать одну (как открытие пака) + открытие следующего рудника.

## 7. Что нужно в коде

Есть: подсчёт разбитых камней по цвету и с рудой (события `clear`, `ore` в `BoardModel`), крепи/порода/газ
как клетки поля (`LOCK`, `ROCK`, `GAS`), полоска и шапка уровня (`Level`).

Сделать:
1. `BoardModel`: здоровье босса, урон по событиям, ход босса после хода игрока (как `gas_spread`), постановка
   препятствий посреди игры, отметки «сюда ударю».
2. Данные босса: три поля (карты как у `LEVELS`), здоровье, урон, действия по фазам, реплики.
3. `Level`: полоска здоровья с рисками, облачко (реплика + намерение), подсветка клеток, смена поля с отъездом вверх.
4. Автоигрок: бой целиком (`sim_boss=N`) — подобрать здоровье, урон и ходы.

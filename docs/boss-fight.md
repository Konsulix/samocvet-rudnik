# Бой с боссом: логика

Согласовано с владельцем 25.10.2026. Внешний вид боссов прорабатывается отдельно (`docs/boss-art.md`);
здесь — только правила боя. Общий план прогресса — `docs/progression-redesign.md`, эпик E в `docs/backlog.md`.

## 1. Суть

Босс стоит на последней глубине рудника (у Old Adit — 350 м). Бой — уровень из **трёх полей подряд**, как
многоэтапные уровни Royal Match: разбил треть здоровья босса — поле уезжает вверх, снизу въезжает новое.
Каждое поле — одна фаза босса. Поля босса сделаны руками (не генератор), одни и те же для каждой попытки.

## 2. Урон

- Бьют **жёлтые кристаллы**: каждый разбитый жёлтый камень — урон боссу.
- Жёлтый камень **с рудой** (золотые жилы) бьёт втрое сильнее — признак руды здесь работает как уязвимое место.
- Спецфишка, сработавшая на поле, — небольшой урон сверх разбитых ею камней.
- Остальные цвета урона не дают: они нужны, чтобы собирать ряды и спецфишки.
- Числа (25.10, подобраны автоигроком `-- sim_boss=16`): **здоровье 1140**, жёлтый 10, жёлтый с золотом 25,
  спецфишка 15; ходов 30 + 5 на каждом новом поле. Бот: при 1050 здоровья выигрывает ~44%, при 1200 — ~6%
  (резкий порог, выборки малые); 1140 — между ними, с учётом −5% за проигрыш живой игрок проходит со 2–3 попытки.

Руду в бою **не добывают** (у глубины босса нет жилы): в шапке вместо плашек руды — полоска здоровья
с рисками на 2/3 и 1/3.

## 3. Три поля = три фазы

| Поле | Здоровье | Что делает босс |
|---|---|---|
| 1 | 420 → 280 | одно-два простых действия, раз в 3 хода |
| 2 | 280 → 140 | добавляется новое действие |
| 3 | 140 → 0 | действует раз в 2 хода, самое сильное действие |

- Смена поля: последний удар по фазе → короткая реплика босса → поле уезжает вверх, новое въезжает снизу.
  Лишний урон сверх порога фазы не переносится (каждое поле — свой кусок здоровья).
- Форма и препятствия каждого поля — свои (рисуются руками в данных босса).

## 4. Действия босса

- Босс действует **раз в N ходов** игрока; что он сделает, видно **заранее**.
- Все действия собраны из препятствий, которые игрок встречал на глубинах этого рудника («экзамен рудника»).
  Для Old Adit:

| Действие | Что делает | Как ответить |
|---|---|---|
| Кольца | крепи на 4–6 камней | разбить крепи или обойти |
| Обвал | песок/гранит на отмеченные клетки | увести камни из-под отметки |
| Клад | +здоровье за каждый жёлтый камень с рудой на поле | успеть разбить золото |
| Ядовитое дыхание (поле 3) | 3–4 клетки газа | гасить газ, пока не расползся |

## 5. Окно реплик и индикация ударов

Облачко рядом с боссом — одно на всё общение (макет 25.10):
- **реплики**: на старте, при смене поля, на большое комбо, когда теряет фазу, при победе/поражении;
- **намерение**: значок действия + отсчёт ходов («2»), в последний ход перед действием — подсвеченные клетки,
  куда он ударит. Реплика и намерение могут идти вместе: текст сверху, значок с отсчётом снизу.
- Связь с полем — через анимацию: босс бьёт по рамке → камни/крепи падают на отмеченные клетки.

## 6. Ходы, поражение, награда

- Ходы: **число пока не решено** — подбирается автоигроком под цель «живой игрок выигрывает с 2–3 попыток».
  Вариант для начала: общий счётчик на весь бой, при смене поля +5 ходов.
- Поражение (кончились ходы): попытка заново с первого поля; каждый проигрыш снимает боссу 5% здоровья
  на следующую попытку (мягкое поражение).
- Победа: 9 жеод, выбрать одну (как открытие пака) + открытие следующего рудника.

## 7. Что сделано (25.10, ветка `progression`)

- Данные и три поля Полоза — `AREAS[0].boss` в `game_data.json`: «The lair» (широкое, грязь; кольца + клад, раз в 3 хода),
  «The coils» (вырезы змейкой по краям, гранит; + обвал), «The hoard» (сужается, газ и гранит у центра; раз в 2 хода,
  + дыхание, обвал гранитом).
- Правила — `BoardModel`: цель `boss` (здоровье), `_boss_damage`, `boss_floor/top`, `boss_stage_clear`, `next_stage`,
  `boss_plan` (намерение {act, cells}, отсчёт `timer`), `boss_turn` (возвращает {act, cells, removed, heal}).
  Бой — «глубина» на одну ниже последней: `LevelGen.current(depths.size())` → `LevelGen.boss_fight`.
- Временный вид — `scripts/game/level_boss.gd` (`LevelBoss`): здоровье в плашке целей, намерение в строке подсказки,
  реплики тостами, клетки удара обведены красным (`BoardView.marks`) за ход до удара, новое поле падает сверху.
  **Сюда подключать настоящий вид боя** (босс, рамка, облачко, отъезд поля вверх).
- Главный экран: после задачи последней глубины — «Fight · Great Poloz»; следующий рудник — только после победы
  (`Save.d.boss_won`); проигрыш → `boss_tries` (−5% здоровья, до −30%). Награда — «клад» (`scripts/screens/hoard.gd`,
  `Hoard.pick`), **вид утверждён 25.10**: 3D-глыба змеевика с золотыми жилами (`shaders/hoard_rock.gdshader`),
  самородки у подножия; её обвивает золотой змей — сплошное тело с чешуёй (`shaders/hoard_scales.gdshader`,
  `Hoard._tube`), лофтовая голова с надбровьями и жёлтыми глазами, борода (`Hoard._loft`); 9 жеод — корка с тёмной
  трещиной и кристаллами, друзы кварца, пирит. Крутится пальцем, тап выдвигает жеоду, «Crack this geode» — она
  раскалывается, камень показывается окном находки. Удача девяти: `Hoard.LUCK`. Снаряжение **Geologist's lens**
  (`EQUIP` id `lens`, 4 уровня: 1500/3500/7000/12000): у одной случайной жеоды за уровень кристаллы цвета редкости
  и свет из трещины. Пробовали пиксельный оборот из Blender (`hoard_kit.py` + `art/boss/hoard_px.py`) — отклонён,
  3D понравился больше. Ключи: `-- screen=home hoard lens=N`, `bake_thumbs=lens`.
- Ключи: `-- level=1 gen depth=6` — сразу в бой; `sim_boss=N` — автоигрок.

## 8. Что нужно в коде

Есть: подсчёт разбитых камней по цвету и с рудой (события `clear`, `ore` в `BoardModel`), крепи/порода/газ
как клетки поля (`LOCK`, `ROCK`, `GAS`), полоска и шапка уровня (`Level`).

Сделать:
1. `BoardModel`: здоровье босса, урон по событиям, ход босса после хода игрока (как `gas_spread`), постановка
   препятствий посреди игры, отметки «сюда ударю».
2. Данные босса: три поля (карты как у `LEVELS`), здоровье, урон, действия по фазам, реплики.
3. `Level`: полоска здоровья с рисками, облачко (реплика + намерение), подсветка клеток, смена поля с отъездом вверх.
4. Автоигрок: бой целиком (`sim_boss=N`) — подобрать здоровье, урон и ходы.

## 9. Хозяйка Медной горы (Copper Mountain) — обсуждается, 26.10

Каркас тот же (три поля, ход раз в N, намерение заранее). Вид — в ветке «Хозяйка медной горы».

**Линия рудников:** у каждого свой камень-механика. Old Adit — золото (самородок довести вниз: *куда*),
Copper Mountain — малахит (почка растёт: *когда* снять), дальше — условный опал (*что* за камень).

**Малахитовая почка (механика рудника 2):**
- клетка-блок, не двигается, 1–3 слоя (видно по размеру/полосам); раз в 2–3 хода игрока нарастает слой;
- ряд вплотную или спецфишка рядом срезает её → **местная руда** по числу слоёв (1/2/3), убывает из той же жилы;
- перерастание (рост сверх 3): 1–2 соседних камня под **малахитовой коркой** (не двигаются, снимает ряд рядом),
  почка снова в 1 слой;
- рудные зелёные фишки остаются, но реже: `ORE_P` для рудника 2 ≈ вдвое меньше (каждая ~6-я вместо ~3-й);
  недостачу руды за победу добирают почки — подобрать автоигроком.

**Бой:**
- урон — зелёные камни, зелёные с медью сильнее, спецфишки сверху (числа — автоигроком);
- **ящерки** — ультимативные, защиты нет: раз в N ходов Хозяйки ящерки спрыгивают на поле и уносят ~50% зелёных
  камней (любых, с медью и без) — урона они не дают; подгоняют бить зелёными сразу. Досыпка после удара ящерок —
  **без зелёных** (только остальные цвета), каскады из них — обычные;
- **малахитовая корка** — 4–5 камней каменеют;
- **каменный цветок** (поле 3) — большая почка-босс в центре, 3 стадии; распустилась → Хозяйка лечится, 8 клеток
  вокруг под коркой; ряд вплотную срывает лепесток (стадия назад).
- Как часто: ящерки — каждое второе действие Хозяйки. Поле 1 (раз в 3 хода, корка ↔ ящерки) — ящерки раз в 6 ходов;
  поле 2 (+ обвал) — так же раз в 6; поле 3 (раз в 2 хода, цветок ↔ ящерки, корка — вместе с цветением) — раз в 4.
  За бой ~6 налётов. Число уточнит автоигрок.
- Местная руда — Copper (имя не меняем). Вид второго поля — в другом чате.

**Ассеты под механику** (кроме самой Хозяйки, её фона и рамки — они в ветке вида):
- почка: 3 стадии (1/2/3 слоя) + осколки малахита для `FxLayer.shards` + иконка цели в шапке;
- корка: накладка на фишку (как крепь) + осколки;
- каменный цветок: 2x2 по центру, бутон → 3 стадии → цветение, отдельные лепестки (срываются ударом), свечение
  перед цветением (шейдер);
- ящерка: вид сверху, бег (4–6 кадров), «схватила камень», в стиле поля; она же — значок намерения;
  **сделано (26.10, ветка вида):** 8 кадров бега `art/boss/mistress_frame/lizard_<i>.png` (`art/boss/lizard.py`),
  налёт — превью `art/boss/lizard_raid.gif` (`lizard_raid.py`): за ход до налёта клетки-цели пульсируют бледно-
  зелёной рамкой; на каждый уносимый камень — своя ящерка, стартуют с шагом 0,14 с; прыжок с ближайшего бруска
  (короткое увеличение), бег по прямой к камню (~230 pt/с, на поле ×1,35 крупнее, чем на рамке), камень
  сжимается к пасти (0,16 с) и едет у головы, поворачиваясь с ней («схватила камень» — не отдельный рисунок:
  спрайт фишки, подходит и для зелёной с медью), бег назад на брусок и прочь вдоль него с затуханием; клетка пуста
  → досыпка без зелёных. Весь налёт ~1,5–2 с. На рамке ящерки не пересекаются (дистанция 44 pt, ждут/разворачиваются).
- зелёная фишка с медью: жилы медно-красные вместо золотых (`ORE_LOOK`/`ore_overlay` для рудника 2);
- порода рудника для поля (строка в `board_kit.py` ROCKS, напр. змеевик/малахитовая порода) и фон уровня;
- награда: клад Хозяйки (малахитовая шкатулка с 9 жеодами, 3D как у Полоза);
- звук: музыка боя, шорох/писк ящерок, хруст корки, звон цветения.

**Сделано 26.10 (бой Хозяйки в коде, `AREAS[1].boss`):** id `mistress`, 1140 здоровья, слабость — зелёные (2), урон как у Полоза.
- Поле 1 «The malachite hall»: раз в 3 хода, корка ↔ ящерки. Поле 2 «The vein»: раз в 3, корка, ящерки, обвал, ящерки.
  Поле 3 «The stone flower»: раз в 2, цветок ↔ ящерки; цветок 2x2 в центре (буква `F` на карте).
- Корка — действие `crust` (`n` камней, `LOCK = 2`); обвал — `rockfall` с `hard` (у Хозяйки 2 удара, вид — змеевик,
  `BoardSprites.granite()`); ящерки — `lizards` (`share` 0.5, сделано в соседней сессии: `lizard_marks`, `BossLizards.raid`).
- Цветок (`BoardModel.flower`, клетки `FLW`): стадия 1..3 колец; ряд вплотную или удар срывает внешнее кольцо (раз за взрыв,
  не ниже бутонов), её ход `flower` наращивает кольцо, полный — цветёт: +`heal` (60, не выше доли поля), корка на `crust` (6)
  камней вокруг, снова бутон. Вид — `BoardView._draw_flower` (пиксели, свечение перед цветением), срыв — `FxLayer.petals`.
- Звуки боя — `B.sfx` в данных (hurt, phase, crust, rockfall, lizards, grow, bloom) → `LevelBoss.sound`.
- Автоигрок (`-- area=1 sim_boss=16`): 13% побед при полном здоровье, 19% при −10%, 63% при −20%, 75% при −30% — как у Полоза.
- Проверка: `-- area=1 level=1 gen depth=6 boss_stage=0..2`.

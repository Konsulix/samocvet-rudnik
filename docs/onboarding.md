# Обучение: что объяснять, где и кем

Сюжет и рассказчики — `docs/story.md`. Здесь — каждая механика: где игрок впервые с ней встречается и как её подать.
Собрано по коду и данным 30.10 (`LevelGen.TIERS/AREA_TIERS/NODULES`, `BOOSTS[].at`, `AREAS[].boss.stages`).

## Правила
- Одна новинка за раз, в момент первой встречи — не заранее.
- Можно показать — показываем, а не рассказываем.
- Всё объяснённое можно перечитать: тап по значку цели на поле, записка в атласе.
- Сюжет не держит игрока дольше пары тапов.

## Каналы
| Канал | Что это | Для чего |
|---|---|---|
| **Показ на поле** | поле притушено, новое подсвечено, рука показывает ход; без текста или одна строка | механика поля при первой встрече |
| **Проводник в сцене** | экран рудника едет к проводнику, жест, облачко 1–2 фразы | новая система и её смысл; предупреждение перед уровнем с новинкой |
| **Портрет** | крупный портрет на затемнённом экране, можно двое | знаковые моменты сюжета (`story.md`) |
| **Справка** | тап по значку цели/препятствия — одна строка; метка «new» в окне уровня | напомнить забытое |

Проводники: Old Adit — старик с трубкой; Медная гора — старый камнерез; Китовая бухта — китобой с компасом;
Огненный горизонт — пока нет (назначить). Портреты в огранённом стиле есть у старика, брата, сестры.

## 3. Препятствия по глубинам
Old Adit (`TIERS`): 50 м песок/грязь → 100 м гранит → 200 м газ → 300 м крепи.
Первый уровень с новым препятствием — только оно, +3 хода (уже в генераторе). Перед ним — проводник в сцене,
на поле — показ.
| Препятствие | Где | Подсказка |
|---|---|---|
| Гранит (2 удара, колется) | Old Adit 100 м | «Granite takes two hits» |
| Газ (растекается) | Old Adit 200 м | «Gas creeps if you leave it. Clear it next to it» |
| Крепи (держат камень) | Old Adit 300 м | «Timber pins a stone. Match it to knock it loose» |
| Змеевик (гранит рудника 2) | Медная гора 150 м | справка — то же, что гранит |
| Почка малахита (растёт, срезать — руда) | Медная гора, сразу | проводник + показ: «Cut it before it spreads crust» |
| Малахитовая корка | Медная гора 250 м (+ от почек) | показ |
| Газ в руднике 2 | Медная гора 350 м | справка |
| Сланцевая плита, льдина, Мальстрём, конкреция | Китовая бухта (план, `mine3-kraken.md` §2) | по мере постройки |
| Заготовка в горне (бить в такт), расплав серы, окалина | Огненный горизонт (план, `mine4-etna.md` §6) | по мере постройки |

## 7. Боссы (`AREAS[].boss`, у всех: здоровье, ходы, действие раз в N ходов, намерение заранее, 3 поля)
Общее для первого боя (Полоз): показ — облачко-намерение, полоска здоровья, урон «слабым» цветом (`weak`) и рудой,
спецфишки сильнее. Перед боем — портрет (проводник напротив босса), после — портрет (осколок выбит, брат).
| Босс | Действия по полям | Новое, что показать |
|---|---|---|
| Полоз | кольца + клад → + обвал → + дыхание | намерение, клад копится (`hoard`) |
| Хозяйка | корка + ящерки → + обвал → цветок + ящерки | ящерки уносят зелёные; каменный цветок |
| Кракен | щупальце + чернила → … → + прилив; водоворот, глаз | щупальце рубить по клетке; глаз — окно урона |
| Циклоп | (план) молот, мехи, расплав, молния на наковальне | гонка: остудить наковальню |
| Брат (Провал) | 4 фазы = 4 поглощённых босса | без новых правил — экзамен |

# Самоцветный рудник

Мобильная игра: три в ряд в геологической обёртке. Каждый уровень — раскопка образца минерала, который потом можно рассмотреть в 3D, огранить, вставить в украшение или продать. Деньги идут на технику, которая открывает новые глубины рудника.

## Структура

- `godot/` — нативная версия на Godot 4 (в работе).
- `prototype/web/` — браузерный прототип, песочница для механик.
  - `samocvet_src.html` + `specimen.js` → `python build_samocvet.py` → `samocvet.html` (игра) и `vitrina.html` (витрина минералов).
- `prototype/early/` — ранние прототипы («Забой», «Жила» и другие).
- `prototype/history/` — патчи и бэкапы, по которым шла разработка прототипа.
- `prototype/tools/` — скрипты генерации картинок (ключ API берётся из переменной окружения `OPENROUTER_API_KEY`).

## Запуск прототипа

Открыть `prototype/web/samocvet.html` через любой локальный веб-сервер, например:

```
cd prototype/web
python -m http.server 8765
```
